# Data attribution and source meaning

Public factual aggregate counts originate from [PyPI download statistics](https://docs.pypi.org/api/bigquery/) maintained by the Python Software Foundation and are delivered by the PSF-hosted [PyPIStats API](https://pypistats.org/api/). PyPI explicitly identifies its tables and data as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribution: PyPI / Python Software Foundation; PyPIStats.org. This repository selects date/category/package/count fields, creates a fixed calendar projection and adds accounting, scores and figures. These are modifications; no endorsement is implied. Our MIT code license does not replace CC BY 4.0 for source data.

Twelve exact decoded response entities remain private with safe capture/hash receipts. Public source fields include the fixed 150-date projection and an out-of-window qualification ledger. These are aggregates, not IP/client/person-level logs. The [source verification](data/source_verification.json) independently reconstructs counters from the exact originals through SQLite JSON1.

Publisher implementation inspected before cohort acquisition: [overall SQL](https://github.com/psf/pypistats.org/blob/2f8271dc7ff1c3fbbbb4f9c09de68f41978cb4ea/pypistats/tasks/pypi.py) and [API parameter handling](https://github.com/psf/pypistats.org/blob/2f8271dc7ff1c3fbbbb4f9c09de68f41978cb4ea/pypistats/views/api.py). The URL revision is the observed Git tree, not a claimed commit. Private canonical text matches publisher Git blob identities e51531a3202b5304aaeef3d559698c6794c6ad55 and 18bd13b91add14b9f5e5433c0b45ef402510e77d. Third-party code is not copied into this project or executed.

The inspected query limits Python-version strings (or NULL), then removes four named mirror clients using NOT IN. [GoogleSQL NULL semantics](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/operators#in_operator) also exclude unknown installers from the filtered counter. We therefore use **publisher-filter-removed traffic**, not a measured exclusive mirror count. This is an inference from inspected code and SQL semantics, not a deployment audit of each historical day. [CI/CD is included and mirror end-user requests are unobserved](https://pypistats.org/faqs). Counts cannot establish actual users, all automation, demand, incidents or adoption.

No raw event logs, IP addresses, package files, credentials, account details, private personal/clinical data, third-party expressive prose or formal-publication drafts are included.
